# Go 企业智能客服与知识运营平台

这是一个使用 Go 构建、面向真实工程问题的多租户企业智能客服与知识运营平台。

> 当前状态：项目立项。仓库目前只包含产品范围和交付规划，尚未完成 AI 接入，也不声称已经生产部署、达到特定性能或取得业务收益。

## 要解决的问题

企业客服需要依据本企业当前有效的知识回答客户问题，同时遵守租户和用户权限，并安全地连接订单、工单等业务系统。模型能够生成文本并不代表系统可以直接上线；检索依据、权限校验、工具执行、失败处理和操作审计都必须由外围系统明确控制。

## 第一个完整里程碑

第一阶段将实现：企业管理员发布带版本的知识文档后，客户可以得到以下两种确定结果之一：

- 根据当前租户有效文档生成、并带有来源引用的回答；
- 没有充分依据时返回明确的“无法回答”，而不是由模型编造内容。

在扩展业务工具和更复杂的智能体能力前，第一阶段必须先验证租户隔离、文档版本可见性、来源引用和失败行为。

## 规划能力

- 租户范围内的文档处理和版本管理
- 语义检索与关键词检索
- 带来源引用的知识回答
- 客服会话和人工接管
- 订单查询、工单创建等受审计的业务工具
- 离线评测、回归检查、延迟和成本观测
- 可替换的模型与向量生成服务

## 初步技术方向

- Go：接口、业务编排、权限、流程和可靠性
- PostgreSQL：权威业务数据
- pgvector：需要向量检索时引入
- Python：只用于适合模型实验或数据处理生态的部分

基础设施只在具体业务需求出现时加入。第一阶段不预设必须使用 Redis、Kafka 或 Kubernetes。
